# PMx — productmarketing.team

The PMx website, hosted on Netlify. Netlify publishes these files
automatically whenever a change is pushed here.

## Pages

| File                | What it is                                  |
|---------------------|---------------------------------------------|
| `index.html`        | Homepage (Product Marketing Multiplier)     |
| `deliverables.html` | "Pick a Seat" interactive simulation        |

Each page is fully self-contained (styling, scripts, and images are built
into the file). The pages link to each other by filename.

## How to publish a change
1. A change is made to a file above (Claude Code can do this for you).
2. It's committed (a saved snapshot) and pushed to GitHub.
3. Netlify auto-publishes the update, usually within a minute.
